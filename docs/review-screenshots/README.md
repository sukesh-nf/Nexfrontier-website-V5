# Review Screenshots

This folder is reserved for screenshots of the NexFrontier v4 preview deployment.

## How to generate screenshots

The Bolt environment does not have a headless browser available to capture
screenshots programmatically. To populate this folder:

1. Open the preview deployment URL in a desktop browser at 1440px width
2. For each page listed below, take a full-page screenshot
3. Name files using the convention: `{route}-desktop.png` or `{route}-mobile.png`
4. For mobile screenshots, set viewport to 390px width
